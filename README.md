# 真·拿命验收

绝区零一条龙第三方插件：自动重复挑战第二章间章 HDD 战斗委托「真·拿命验收」，换取微量丁尼。

原为主程序内置应用（作者 DoctorReid），本仓库是其插件化迁移版本，代码逐字提取自主程序官方 main，仅做插件化必需的最小适配（相对导入、元数据、key_sim 样例自包含）。

## 使用

1. 将本仓库 Release 的 zip 导入主程序「资源管理 → 插件管理」，或解压到主程序 `plugins/life_on_line/`；
2. **编队需 1 号位妮可、2 号位比利**（按键脚本按此配队录制，其他配队会卡住）；
3. 在一条龙列表勾选运行，可设置每日次数与预备编队。
